# ZOEYA Beauty Lounge — زويا بيوتي لاونج (نسخة عرض)

موقع كامل (عربي + إنجليزي) لـ **زويا بيوتي لاونج ZOEYA** — لاونج تجميل أنثوي في
**التجمع الخامس** و**المعادي** بالقاهرة. مبني بـ **HTML/CSS/JS خالص** (ثابت، بلا خادم):
سريع، متوافق مع الجوال، مناسب لـ SEO، ويعمل على أي استضافة ثابتة مجانًا.

> ⚠️ **نسخة عرض — الأسعار والصور توضيحية** وتُستبدل بالمحتوى والصور الرسمية عند التعاقد.

---

## 1) ما الموجود في المجلد

```
zoeya-website/
├─ index.html              الصفحة العربية (RTL)
├─ en.html                 الصفحة الإنجليزية (LTR)
├─ assets/
│  ├─ css/style.css        التنسيق الكامل (هوية: أبيض/نود · وردي · أسود · ذهبي)
│  ├─ js/main.js           التفاعلات + إرسال الحجز إلى واتساب
│  └─ img/                 صور الخدمات (16 صورة JPEG مضغوطة) + الشعار logo.svg
├─ robots.txt
├─ sitemap.xml
├─ IMAGE-CREDITS.md        مصادر الصور وتراخيصها
└─ README.md               هذا الملف
```

**الأقسام:** هيدر/تنقّل · Hero · شريط أرقام (4.5 ★ / 808 مراجعة / فرعان) · «عن الصالون» ·
«الخدمات» بخمسة أقسام تفاعلية (الأظافر، الشعر، العناية بالبشرة والوجه، الحواجب والرموش، باقات العرائس) —
كل خدمة بصورة · معرض أعمال · «احجزي موعدك» بزر واتساب + نموذج حجز · الفرعان مع خريطة جوجل · فوتر وتواصل اجتماعي.

**الأداء:** الصور مُحسّنة (أبعاد مضبوطة + ضغط JPEG، الإجمالي ≈ 1.7MB بدلًا من 5MB) مع **تحميل كسول (lazy loading)**،
وفتح نسب الأبعاد مثبّت يمنع اهتزاز التصميم (CLS). كل زر «احجبي موعدك» في الخدمات يفتح واتساب برسالة مسبقة تحمل اسم الخدمة.

## 2) المعاينة محليًا

افتح `index.html` مباشرة في المتصفح (دبل كليك) — لا يحتاج أي خادم.

أو عبر خادم محلي بسيط:

```powershell
python -m http.server 8080
# ثم افتح http://localhost:8080/
```

## 4) النشر (استضافة مجانية دائمة)

### الأسرع: Netlify Drop
1. افتح `https://app.netlify.com/drop`
2. اسحب **مجلد** `zoeya-website` كاملًا.
3. يظهر رابط مباشر خلال ثوانٍ؛ أنشئ حسابًا مجانيًا لتثبيته (Deploy → Claim).

### الأقوى لـ SEO: GitHub Pages
1. أنشئ مستودعًا باسم `zoeya-beauty` وارفع محتويات المجلد (Add file → Upload files).
2. `Settings → Pages → Source: Deploy from a branch → main / (root) → Save`.
3. يعمل الموقع على `https://<اسمك>.github.io/zoeya-beauty/`.

### الاحترافي: Cloudflare Pages
`dash.cloudflare.com → Workers & Pages → Pages → Upload assets` ثم ارفع المجلد.

> ملاحظة: الجهاز لا يحتوي على `git`، لذا الرفع عبر المتصفح هو الأنسب. **لم يتم النشر بعد** — الرفع مسؤولية المالك.
